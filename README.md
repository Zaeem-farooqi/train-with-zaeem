# Train with Zaeem

Personal trainer site — Next.js, Tailwind, GSAP, Lenis.

## Setup

```bash
npm install
npm run dev
```

## Edit content

- `config/site.ts` — brand, contact, hero copy
- `config/content.ts` — horizontal section cards and images
- `public/images/` — swap placeholder photos
- `public/brand/logo.png` — logo

## Scripts

```bash
npm run dev
npm run build
npm run lint
```
